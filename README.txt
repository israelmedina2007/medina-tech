PUBLICACIÓN GRATIS
- GitHub Pages: crea repositorio medina-tech, sube todo, Settings > Pages > Deploy from branch > main > root.
- También puedes usar Netlify o Cloudflare Pages.

DOMINIO
Compra un dominio como medinatech.mx, medinatech.com.mx o medinatech.com. Después conecta sus DNS con la plataforma de hosting. Cuando tengas el dominio, cambia TU-DOMINIO.com en index.html, robots.txt y sitemap.xml.

GOOGLE
Después de publicar con dominio propio, entra a Google Search Console, verifica el dominio y envía https://TU-DOMINIO.com/sitemap.xml.
